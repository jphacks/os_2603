# FusenLess（本の付箋アプリ）

<img src="assets/icon.png" width="240" alt="FusenLess アイコン">

### [デモ動画（YouTube）](https://youtube.com/shorts/XNKYjWmO3zk?si=MnbfIdFY68XfvLmP)

> **本はきれいなまま、学んだことは自分に残る。**
> 図書館で借りた本にも、売りたい教科書にも、一切汚さずに付箋とメモを残せるiPhoneアプリです。
> 思い出せない付箋は、紙の教科書に戻って読み直す。デジタルは「どこを読み直すか」を示す役に徹します。

## 製品概要
### 背景(製品開発のきっかけ、課題等）
情報系の分厚い専門書を、図書館で借りて読むことがよくあります。大事なところに線を引きたい、付箋に自分の考えを書き残したい。でも **借りた本には書き込めません**。自分で買った教科書も、きれいに残して売りたいので書き込みたくない。

結局、ノートやNotionに書き写すことになり、**どの本のどの行の話だったのかが分からなくなります**。付箋を貼っても、返却するときに剥がした瞬間、メモは全部消えてしまいます。

事前調査（Webアンケート11名＋対面の聞き取り5名、計16名。学生・大学院生ほか）では、次のような声が集まりました。

- **16人中13人** が、付箋を「何のために付けたか」思い出せないことがある（よくある5人、たまに8人）
- **16人中13人** が、このアプリを「使いたい」「ぜひ使いたい」と回答
- **16人中11人** が、見返すときは本を「パラパラめくって」探している
- **16人中8人** が、付箋が「はがれる・本が膨らむ・本を傷めないか心配」と回答
- **16人中8人** が、借りた本に「書き込みたいのに書けなかった」経験がある
- 自由記述・聞き取り：「一度メモをNotionに書く手間を踏む必要がある」「返却前に付箋を剥がしてノートに書き写す作業がかなり負担」「満員電車で立って読んでいるときはペンや付箋を出す余裕がない。片手スマホですぐマークできると助かる」「自分の本でも、メルカリで売ったり、きれいに残したりしたいので書き込みや付箋を使わない」

そこで私たちは、**物理の付箋で実際にしていること**を一つずつ分解し、良さは残して不便だけを消すことにしました。

物理の付箋には、本を傷めるという問題もあります。短い時間貼っただけでも糊が残り、ページ同士がくっついたり、はがすときに紙の表面ごと文字がはぎ取られたりすることがあります（[東京都立図書館](https://www.library.metro.tokyo.lg.jp/guide/uploads/Q%26A_sticky.pdf)、[米国国立公文書館の試験](https://siarchives.si.edu/blog/post-it-or-not-post-it)）。

| 物理の付箋でしていること | FusenLessでの再現 |
| --- | --- |
| 一瞬で貼る | ホーム画面からカメラを開き、指で囲むだけで付箋ができる |
| 本の側面から、どこに付箋があるか分かる | 本を横から見た「小口ビュー」に付箋のタブが飛び出す |
| パラパラめくって、周りの文章で「この話だった」と思い出す | 付箋の周りの数行を残す「パラパラモード」。本がなくても見返せる |
| たくさん貼っても区別できる | 端末内AIが付箋ごとに一言の見出しを付ける。色に名前を付けられ、全付箋を検索できる |
| 覚えたら剥がす | 指で剥がすとゴミ箱へ。30日後に自動で完全削除。いつでも戻せる |
| 思い出せなければ本を開いて読み直す | 復習画面で思い出せない付箋は、ページ番号を示して紙の教科書に戻す |

### 製品説明（具体的な製品の説明）
1. **本を選ぶ**：ISBNバーコードをかざすと書名と著者を補完して登録。ホーム画面のカメラボタンからすぐ撮影に入れる
2. **囲んで貼る**：ページを撮り、付箋を貼りたい部分を **指で囲むだけ**。囲んだ範囲だけを端末内でOCRし、触覚フィードバックとともに付箋が完成。ページ番号も自動で読み取る
3. **撮り直すと戻る**：次に同じページを撮ると、付箋とメモが **元の位置に自動で戻る**
4. **本がなくても思い出す**：付箋の周りの数行と、AIが付けた見出しで、パラパラモードで見返せる。小口ビューで付箋の位置もひと目で分かる
5. **振り返る**：復習画面で付箋の見出しと目印を見て、「ここに付箋を貼った理由」を思い出す。思い出せなければ、**ページ番号を大きく示して紙の教科書へ戻す**。本が手元になければ「あとで教科書で確認」に残し、読み直したら記録する。忘れかけた頃には通知が届く
6. **覚えたら剥がす**：付箋を指で剥がすとゴミ箱へ移り、30日後に自動で完全削除。いつでも戻せる

> **ページ全体の画像は保存しません。** 保存するのは「本・ページ番号・目印の文字列・付箋の周りの数行・メモ」だけ。メモは端末内で暗号化して保存します。

### 特長
#### 1. 囲むだけで、すぐ貼れる
ホーム画面からカメラを開き、ページ番号も自動で読み取ります。あとは貼りたい部分を指で囲むだけ。囲んだ範囲だけをOCRするので速く、ページ全体の文字は読みません。
電車などで撮れない場面のために、**ページ番号と声だけで先にメモを残せるモード** もあり、後でそのページを撮って囲むと配置されます。

チーム内の計測では、「教材を選ぶ → 範囲を選ぶ → 付箋の内容を書く → 完了」までの時間が **物理の付箋 20〜30秒 → FusenLess 約19秒** でした。簡単なメモを「貼るだけ」で比べると、物理の付箋 約10秒 → FusenLess 約8秒です。

#### 2. 本が手元になくても思い出せる
付箋の周りの数行と、端末内AIの一言見出しを残すので、本を返したあとでも「この話だった」と思い出せます。パラパラモードでページ順にめくり、小口ビューで付箋の位置をひと目で確認できます。

#### 3. 復習はアプリで完結させず、紙の本に戻す
物理の付箋には、手で書くことで記憶に残るという良さがあります。一方、アプリで答えを見て、予測変換で入力して済ませると、分かったつもりのまま進んでしまいます。
そこでFusenLessの復習画面は、**アプリの中で学習を完結させません**。付箋の見出しと目印から「ここに付箋を貼った理由」を思い出してもらい、思い出せなければ **ページ番号を示して紙の教科書へ戻し、本文や図を読み直してもらいます**。必要なら紙のノートに自分の言葉で書き直すことも促します。本が手元にないときは「あとで教科書で確認」の一覧に残り、読み直したら記録されます。
この設計は学習研究にもとづいています。文章を読んだあと、思い出すテストをした人は1週間後に61%を覚えていたのに対し、読み直しただけの人は40%でした（[Roediger & Karpicke, 2006](https://source.washu.edu/2006/03/repeated-testtaking-better-for-retention-than-repeated-studying-research-shows/)）。また、間隔をあけて復習する方が記憶に残ることも、184本の論文の分析で示されています（[Cepeda et al., 2006](https://www.yorku.ca/ncepeda/publications/CPVWR2006.html)）。FusenLessは見出しから思い出させ、思い出せなければ紙の教科書に戻し、忘れかけた頃に通知します。

#### 4. 覚えたら、剥がす
物理の付箋の「覚えたら剥がす」気持ちよさを残しました。付箋を指で剥がすとゴミ箱へ移り、30日後に自動で完全削除。付箋が増え続けて大事なものが埋もれるのを防ぎます。剥がした付箋はいつでも戻せます。

### 解決出来ること
- 借りた本・売りたい本でも、**汚さずに** 自分の本のように書き込みながら学べる
- 付箋が **どの行を指しているか** がはっきりし、撮り直せば元の位置に戻る
- **本が手元になくても**、周りの文章とAIの見出しで内容を思い出せる
- 付箋が増えても、見出し・色の名前・検索で **すぐに探せる**（本をまたいで全付箋を検索）
- ノートやNotionへの **書き写しの手間がなくなる**（付箋と周りの文章がアプリに残る）
- 思い出せない付箋は紙の教科書に戻って読み直すので、**分かったつもりで終わらない**

### 今後の展望
- 付箋を付けるまでの時間のさらなる短縮（事前調査では16人中14人が「10秒以内」を希望）
- **同意した人同士での付箋の共有**：事前調査では16人中9人が「前に借りた人のメモを見たい」と回答し、自分のメモを公開してよい（匿名なら・そのままを含む）人も16人中11人いた
- カメラをかざすだけで付箋が浮かぶリアルタイム表示
- 図や数式への付箋（画像の特徴による位置合わせ）
- 縦書きの本への対応、OCR前処理の強化

### 注力したこと（こだわり等）
* **ユーザーの声で設計を磨いた**：事前調査の「Notionに書き写す手間がある」「返却前に付箋を剥がしてノートに書き写すのが負担」という声から、付箋と周りの文章をアプリに残す設計に。「満員電車ではペンや付箋を出せない」という声から、写真なし・声だけのメモモードを実装。スポンサー企業の方からいただいた「撮った写真の中で範囲を選ばせ、そこだけOCRすれば速く正確になる」「アプリを開いてから付箋を貼るまでを速く」という意見を受け、範囲選択OCRと、ホーム画面からすぐカメラを開ける流れに作り替えた
* **物理の付箋の分解**：物理の付箋の良さ（すぐ貼れる・位置が分かる・周りで思い出せる・剥がす気持ちよさ）と不便（汚す・はがれる・本がないと見られない）を洗い出し、良さは残して不便だけを消すことを設計の軸にした
* **「本を読まない・保存しない」設計**：囲んだ範囲だけをOCRし、ページ画像は保存しない。軽量で、プライバシーと著作権に配慮
* **付箋の配置はAIではなくアルゴリズム**：再撮影時の位置合わせは文字列のあいまい一致で確実・高速に行い、AIは付箋の見出しと要約に限定した
* **復習をアプリで完結させない**：アプリで答えを見て終わるのではなく、思い出せない付箋は紙の教科書に戻して読み直す設計にした。デジタルは「どこを読み直すか」を示す役に徹する

## 開発技術
### 活用した技術
#### API・データ
* openBD（ISBNから書名・著者を補完。失敗時は手入力）
* OCR・AI・音声認識・保存はすべて端末内で処理（本文やメモは外部に送信しない）

#### フレームワーク・ライブラリ・モジュール
* **SwiftUI / SwiftData**：画面とデータ保存
* **Vision**：日本語OCR（範囲を指定した認識）、ページ番号の検出
* **AVFoundation**：高速に起動する独自のカメラ画面
* **VisionKit（DataScannerViewController）**：ISBNバーコードの読み取り
* **Foundation Models**：端末内LLMによる付箋の見出しと要約の生成（非対応端末では簡易生成にフォールバック）
* **Speech**：声でのメモ入力（端末内認識を優先）
* **CryptoKit / Keychain**：メモの暗号化
* **UserNotifications**：忘れかけた頃の復習通知（SM-2を簡略化した間隔の調整）

#### デバイス
* iPhone（iOS 18以降。端末内AIはiOS 26以降のApple Intelligence対応端末）

### 独自技術
#### ハッカソンで開発した独自機能・技術
* **範囲選択OCRと座標の復元**：指で囲んだ範囲だけをVisionで認識し、その結果を元のページ画像の座標に戻して付箋を配置する
  * [`FusenLess/ios/Sources/OCR.swift`](./FusenLess/ios/Sources/OCR.swift)
* **目印のあいまい一致による付箋の自動復元**：付箋を付けた文字列を目印として保存し、再撮影時にOCRの読み間違いがあっても、文字列の類似度（Levenshtein距離）で元の位置を見つける。複数行にまたがる付箋にも対応
  * [`FusenLess/ios/Sources/Matching.swift`](./FusenLess/ios/Sources/Matching.swift)
* **画像を保存しない付箋モデル**：本・ページ番号・目印・周りの数行・暗号化したメモだけを持つ
  * [`FusenLess/ios/Sources/Models.swift`](./FusenLess/ios/Sources/Models.swift)
* **剥がす体験**：長押しして左右にスワイプすると付箋が剥がれ、ゴミ箱へ移るジェスチャー
  * [`FusenLess/ios/Sources/PeelModifier.swift`](./FusenLess/ios/Sources/PeelModifier.swift)
* **紙の本に戻す復習画面**：思い出せない付箋をページ番号つきで「あとで教科書で確認」に残し、読み直した記録を「覚えた」とは別に保存する
  * [`FusenLess/ios/Sources/ReviewView.swift`](./FusenLess/ios/Sources/ReviewView.swift)
* **小口ビュー**：付箋のページ位置を、本を横から見た絵のタブとして表示
  * [`FusenLess/ios/Sources/BookSpineView.swift`](./FusenLess/ios/Sources/BookSpineView.swift)

> ソース一式は [`FusenLess/ios/`](./FusenLess/ios) を参照。
